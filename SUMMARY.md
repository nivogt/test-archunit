### 3. ✅ ArchUnit License Guardrails

**Location**: `src/TestArchUnit.Architecture/`

#### License Compliance Tests:

**🚫 NoGpl3LicensedDependencies** (CRITICAL)
- Blocks all GPL 3.0 licensed packages
- Prevents viral copyleft issues
- Scans dependencies via ArchUnitNET

**✅ OnlyApprovedLicensesUsed**
- Whitelist: MIT, Apache 2.0, BSD, ISC
- Validates all NuGet packages
- Implementation: `NuGetLicenseValidator.cs`

**🏗️ ControllersShallDependOnInterfaces**
- Enforces dependency injection patterns
- Ensures testability

**📝 PublicClassesHaveMeaningfulNames**
- Blocks generic names (Class1, Class2)
- Improves code quality

**📂 ControllersAreInControllerNamespace**
- Enforces architecture layering
- Maintains separation of concerns

#### Custom Validator Classes:

**NuGetLicenseValidator.cs** (Main Engine)
```csharp
public class NuGetLicenseValidator
{
    // Approved: MIT, Apache-2.0, BSD, ISC, MPL-2.0
    // Blocked: GPL-3.0, AGPL-3.0, GPL-2.0
    
    public IEnumerable<LicenseViolation> ValidateProjectFile(string projectFilePath)
    {
        // Parses project.assets.json
        // Checks each package against whitelist/blacklist
        // Returns violations
    }
}
```

**Supported License Detection**:
- Reads `project.assets.json` (auto-generated by dotnet restore)
- Extracts package and license information
- Compares against predefined lists
- Generates actionable violation reports

## 🔍 How It Works

### GPL 3 Detection Flow

```
Developer adds package
    ↓
dotnet restore
    ↓
Creates project.assets.json
    ↓
NuGetLicenseValidator reads file
    ↓
Extracts license metadata
    ↓
Checks against prohibited list
    ↓
If GPL-3.0/AGPL-3.0 found:
  → LicenseViolation reported
  → Test fails: ❌ NoGpl3LicensedDependencies
  → GitHub Actions: Red X on PR
  → Must remove or replace package
    ↓
If only approved licenses:
  → All tests pass: ✅
  → GitHub Actions: Green check mark
  → Ready to merge
```
